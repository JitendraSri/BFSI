📂 Datasets & How They Power This Platform

Every feature is built on a specific dataset. Here's exactly what data we used, what it contains, and how we trained or used it.

🏦
BankSim / PaySim — Synthetic Transaction Dataset
🔍 Fraud Detection 📊 Model Training
What it contains
  • 500,000+ synthetic bank transactions
  • Fields: amount, merchant, channel, timestamp, customer ID, fraud label (0/1)
  • Channels: online, ATM, POS, mobile, branch
  • Class imbalance: ~1–2% fraud (realistic)
How it's used in training
  • Preprocessed: label-encoded channel & merchant
  • Trained a Random Forest Classifier (scikit-learn)
  • Features: amount, channel_enc, customer_id, kyc, account_age
  • Saved as fraud_model.pkl + encoder.pkl
  • Live inference on every uploaded transaction
📈
Your Uploaded Bank Statements
📉 Spending Forecast 🔴 Anomaly Detection 🔄 Recurring Payments 🧮 Credit Score
What it contains
  • CSV / Excel / PDF bank statements you upload
  • Fields: date, description, amount, direction (debit/credit), category
  • Normalised & deduplicated on import
  • Stored in MongoDB per user — private & isolated
How it's used
  • Forecast: 3-month Simple Moving Average on monthly debits
  • Anomaly: Isolation Forest on amount + frequency per category
  • Recurring: Frequency clustering on description + amount
  • Credit score: fraud ratio, months of data, activity count
📄
Your Uploaded Financial Documents (FinRAG)
🔎 FinRAG Q&A 🔒 Private · On-server
What it contains
  • PDFs, HTML, Markdown, TXT you upload
  • E.g. your bank statements, loan docs, insurance PDFs
  • Up to 10 MB per document
How it's processed (RAG pipeline)
  • Text extracted & split into overlapping chunks
  • Each chunk embedded via Gemini Embedding API
  • Stored in a local JSON vector index (no cloud)
  • At query time: BM25 + dense retrieval → reranker → Gemini LLM
  • Answer includes page-level citation — traceable & verifiable

🔒 Why FinRAG Over ChatGPT / Claude?

FinRAG Copilot is purpose-built for your private financial data — not a generic chatbot.

Feature FinRAG Copilot ChatGPT / Claude
Data stays on your server ✅ Yes — local vector index ❌ Sent to OpenAI/Anthropic
Trained on your documents ✅ RAG over your PDFs ❌ Generic knowledge only
Answers cite source document ✅ Page-level citations ❌ No source traceability
No data used for model training ✅ Never used for training ⚠️ Depends on plan
BFSI domain context ✅ Finance-specific prompts ⚠️ General purpose
Works offline / on-premise ✅ Can run locally ❌ Cloud-only

🛡️ How your data is kept secure

  • All uploaded documents are stored in your MongoDB instance — not a shared cloud.
  • Documents are chunked and embedded server-side using Gemini Embedding API — only the text chunk (no personal info) is sent for embedding.
  • Your transaction data and statement PDFs are never sent to any external LLM for training or storage.
  • Every API endpoint is protected by JWT authentication — no anonymous access.
  • Rate limiting, OTP verification and input sanitisation are applied across all sensitive endpoints.
